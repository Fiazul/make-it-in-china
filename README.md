# Make It in China

Browser game in three.js that teaches HSK Mandarin by making the player earn a living in it. Working title.

## Status

**v0.0.1** — M1 vertical slice (grey box): one street, noodle shop dishwasher job, 3 scenes, 150 HSK 1 words in the dictionary.

## Quick Start

```bash
npm install
npm run dev       # Open the URL Vite prints
npm test
npm run check:content
npm run build
```

Optional: append `?toon=1` to the URL for toon shading.

## How to Play

- Click or tap the street to walk.
- Stand next to the cook at 面馆 to start a shift.
- Tap any hanzi for pinyin and gloss.
- Wrong replies cost a yuan and show a consequence; you never lose the game.
- Notebook button 词本 in the bottom-right; export/import save strings there.
