# Engine
Pure TypeScript gameplay rules and state transitions, independent of the browser and renderer.

- `dialogue.ts` — dialogue lifecycle and reply routing.
- `economy.ts` — wallet, action-slot, rent, and day rules.
- `index.ts` — public engine exports.
- `learner.ts` — word progress, evidence, and decay.
- `progress.ts` — durable progression, day slots, scene scheduling, and the gate query.
- `save.ts` — save validation and serialization.
- `slots.ts` — scene validation and slot filling.
- `store.ts` — game API, state, and event glue.
- `types.ts` — engine contracts and shared types.
